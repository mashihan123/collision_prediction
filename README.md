Traffic Collision Prediction with GAT

Graph Attention Networks (GAT) are implemented for traffic accident prediction, where vehicles are represented as individual nodes in the graph and the vehicle classes serve as key node features. The prediction framework encompasses graph classification (predicting occurrence of a traffic accident). The GNN model achieves 86.1% accuracy in graph classification. The prediction framework offers new opportunities for enhancing collision warnings and improving safety measures.
The Single_Graph_BC.ipynb includes codes and experimental results from GAT + Binary Classification model, and the LSTM_Node_GAT.ipynb includes codes and experimental results from LSTM + GAT + Binary Classification model.

In the "csv_final" directory, normal scenes (csv_final/normal) and accident scenes (csv_final/accident) data are summarized, as well as the information for each accident scenes (csv_final/info).
